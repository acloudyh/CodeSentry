# CodeSentry 功能清单

更新日期：2026-11-12。本文按当前菜单和已实现行为整理，可直接用于功能核对、使用说明及交付沟通。数据组织为「业务项目 → 扫描资产 → 扫描记录 → 问题、审核与整改报告」。

## 菜单与详细功能表

| 菜单大类 | 功能点 | 详细说明 | 范围与规则 |
| --- | --- | --- | --- |
| 仪表盘 | 总体概览 | 展示业务项目、代码/JAR 资产、未归属数量、执行中扫描及累计新增问题 | 后端全量统计；扫描批次与累计新增不受最近 200 条限制，累计新增不代表当前待整改数量 |
| 仪表盘 | 最近扫描 | 查看最近的扫描执行记录并进入明细 | 沿用原扫描编号 |
| 仪表盘 | 最近发现问题 | 按发现时间展示最近问题及等级 | 审核详情在问题台账查看 |
| 项目概览 | 新建、编辑业务项目 | 维护项目名称与备注 | 备注在列表独立列单行展示，超长省略 |
| 项目概览 | 多资产归属 | 一个项目关联多个本地代码库、Git 仓库及 JAR，支持混合管理 | 一个资产同一时间只归属一个业务项目 |
| 项目概览 | 关联已有资产 | 将已登记的未归属资产纳入业务项目 | 不复制资产或历史扫描 |
| 项目概览 | 解除归属 | 解除资产与业务项目的关联 | 保留资产及原始扫描、审核、报告记录 |
| 项目概览 | 未归属资产 | 展示未关联项目的代码与 JAR 数量，并进入资产管理 | 老资产可继续关联已有项目 |
| 项目概览 | 项目删除 | 删除空业务项目 | 仅允许删除无资产、无项目扫描轮次的项目 |
| 项目详情 | 顶部统计 | 展示资产数量、当前扫描范围、完成情况、待审核和已采纳问题数 | 随所选扫描记录更新 |
| 项目详情 | 资产清单 | 查看来源类型、运行环境、分支或文件、代码拉取状态及本次扫描状态 | 支持代码和 JAR 混合展示 |
| 项目详情 | 整项目扫描 | 一次提交，分别为各资产生成独立任务 | 项目批量扫描使用全量方式；超出并发容量排队 |
| 项目详情 | 勾选或单项扫描 | 扫描所选资产，或对一个资产单独发起扫描 | 明确显示部分资产范围 |
| 项目详情 | 统一扫描配置 | 统一选择本地或联网模式及规则集，代码资产分别指定目标 | JAR 使用已保存版本 |
| 项目详情 | 轮次与子任务进度 | 查看各资产的执行状态、异常原因、来源扫描和实际版本 | 项目轮次保存当时的范围与配置 |
| 项目详情 | 取消及失败重试 | 停止项目轮次的活动任务，或重新提交失败项 | 重试创建关联的新轮次，保留原轮次 |
| 项目详情 | 历史扫描兼容 | 按当前资产归属展示未纳入项目轮次的原有单资产扫描 | 标记「资产历史扫描 #原编号」；只读映射，不补造项目轮次、不重扫 |
| 项目详情 | 历史分页与排序 | 项目扫描和资产历史按实际扫描时间统一排序、分页 | 不受全局最近 200 次扫描列表限制；同一扫描不重复显示 |
| 项目详情 | 历史台账和报告 | 从历史扫描进入原问题、审核、报告及验收 | 保留原扫描 ID、问题 ID 和来源记录；历史报告使用原单资产导出流程 |
| 扫描资产 | 发起扫描弹窗 | 在资产行直接打开配置弹窗，选择本地或联网、规则集、全量或增量以及工作区或分支 | 不再单独提供侧栏“发起扫描”菜单；旧扫描链接自动转到资产页，验收复扫锁定原资产、规则集和全量方式 |
| 扫描资产 | 本地仓库登记 | 登记服务端可访问的 Git 工作仓库路径及默认分支 | 校验目录及 Git 仓库有效性 |
| 扫描资产 | 远程仓库登记 | 通过 HTTP、HTTPS 或 SSH 地址登记仓库 | 首次代码拉取在后台执行，保存无需等待 |
| 扫描资产 | 应用类型 | 区分前端、后端和前后端混合应用 | 前端维护 Node.js 版本，后端维护 Java 版本，混合应用可同时维护 |
| 扫描资产 | Node.js 版本 | 提供 14、16、18、20、22、24，以及未确认、自定义版本 | 记录被扫描系统版本，不自动安装或切换运行环境 |
| 扫描资产 | Java 版本 | 记录业务系统实际 Java 版本，用于整改建议 | 与 CodeSentry 服务自身 Java 11 独立 |
| 扫描资产 | Git 账号认证 | 输入账号及密码或访问令牌，支持编辑时保留或清除凭据 | 凭据加密保存；不拼入仓库 URL、不在 API 中明文回显 |
| 扫描资产 | SSH 认证 | 使用服务运行环境中的 SSH 凭据或 ssh-agent | 不通过产品上传和保存 SSH 私钥 |
| 扫描资产 | 校验 Git | 在登记前检查连接、仓库读取权限及分支列表 | 使用轻量远程探测，不克隆仓库或创建扫描资产 |
| 扫描资产 | Git 异常提示 | 区分证书、认证、仓库权限、连接、SSH 主机校验和超时问题 | HTTPS 支持按来源配置专用 CA；不全局关闭证书校验 |
| 扫描资产 | 本地镜像缓存 | 首次拉取后将 Git 镜像持久化在服务端存储目录 | 后续扫描默认使用缓存，不逐次重新克隆 |
| 扫描资产 | 后台同步与重试 | 手动提交同步，显示等待拉取、拉取中、已同步、拉取失败 | 状态自动刷新；失败可重试；同步失败保留已有可用缓存 |
| 扫描资产 | 拉取任务隔离 | Git 拉取使用独立线程池，不占用扫描和模型审核线程池 | 待拉取状态持久化；重启中断任务标记失败；配置版本防止旧任务覆盖新地址 |
| 扫描资产 | 扫描前代码就绪检查 | 首次拉取未完成或代码拉取中时阻止扫描 | 通过可选的扫描前同步更新远端代码 |
| 扫描资产 | 新增 JAR | 上传并保存 JAR，供后续重复扫描 | 首次上传可选择发起扫描；后续不必重复上传 |
| 扫描资产 | 编辑与替换 JAR | 修改名称、Java 版本或替换上传文件 | 原扫描仍引用原保存的文件版本 |
| 扫描资产 | 常规移除 | 从有效资产列表移除登记资产并解除项目归属 | 默认保留历史；不等同于数据库及文件永久清理 |
| 扫描资产 / 扫描弹窗 | 本地扫描 | 使用本地规则和漏洞库进行检测 | 不执行远端代码同步和在线整改依据核实 |
| 扫描资产 / 扫描弹窗 | 联网扫描 | 可同步远程仓库并核实依赖整改版本及依据 | 网络可用性、外部数据源和本地缓存会影响核实结果 |
| 扫描资产 / 扫描弹窗 | 全量扫描 | 对所选完整工作区、分支快照或 JAR 扫描 | 项目批量扫描统一采用全量方式 |
| 扫描资产 / 扫描弹窗 | 增量扫描 | 对代码仓库指定待扫描分支与基线分支进行差异分析 | 保留原单资产增量能力；JAR 不支持源码增量 |
| 扫描资产 / 扫描弹窗 | 当前工作区 | 扫描本地仓库工作区，包含未提交内容 | 不切换原仓库分支、不直接修改业务代码 |
| 扫描资产 / 扫描弹窗 | 分支快照 | 按提交导出独立快照执行扫描 | 保留扫描提交及 merge-base 等基线信息 |
| 扫描资产 / 扫描弹窗 | 规则集选择 | 按场景选择本地或社区通用规则集 | 实际执行取决于扫描器启用和可用情况 |
| 扫描资产 / 扫描弹窗 | 安全检测引擎 | 集成 Semgrep、Gitleaks、Trivy、SpotBugs、P3C | 规则覆盖、源码语言、字节码或依赖信息决定检测范围 |
| 扫描记录 | 执行记录 | 查看批次、资产、扫描方式、状态、数量与时间 | 可进入扫描详情、问题台账及报告 |
| 扫描记录 | 工具执行明细 | 查看各扫描器的阶段、进度、执行日志和失败信息 | 输出按现有脱敏规则处理 |
| 扫描记录 | 停止任务 | 停止尚未完成的扫描及子进程 | 保留已完成记录和停止状态 |
| 扫描记录 | 版本追踪 | 查看扫描分支、基线、提交、快照或保存的 JAR 版本 | 历史扫描不随资产当前版本替换 |
| 问题台账 | 业务项目统一入口 | 只列出实际创建的业务项目，默认选中并记住上次选择 | 不再提供「单资产历史台账」平级选择项 |
| 问题台账 | 项目与历史筛选 | 选择项目扫描或资产历史，按资产、等级、人工结论、报告采纳和关键字筛选 | 历史扫描保留来源；失败资产不使用旧结果补齐 |
| 问题台账 | 顶部数量统计 | 展示本次问题、新增或重新打开、已修复及筛选结果条数 | 总数覆盖全部分页；轮次和资产决定统计范围 |
| 问题台账 | 问题明细 | 展示问题编号、来源扫描、资产、扫描器、规则、等级、位置及建议 | 相同漏洞跨资产保留独立问题 |
| 问题台账 | 代码详情 | 从本地扫描快照展示命中行、行号和上下文 | 项目与单资产详情一致；文件不可读时说明原因 |
| 问题台账 | 人工复核 | 确认风险、误报、接受风险、已整改待验证，并记录复核说明 | 支持复核人及可选风险接受到期时间 |
| 问题台账 | 批量人工复核 | 勾选本页问题，跨资产按来源扫描分组保存结论 | 切换筛选或分页清空勾选，避免隐藏条目被操作 |
| 问题台账 | 批量工具审核 | 按当前扫描范围及资产选择发起整批模型审核 | 窗口明确范围；问题勾选、等级和关键字不缩小整批工具审核范围 |
| 问题台账 | 工具审核过程 | 展示初审、复审、综合建议、置信度、证据和执行进度 | 依赖漏洞按文件与版本合并审核；支持停止、查看详情及失败项重试 |
| 问题台账 | 报告采纳 | 区分已采纳、未采纳和待审核，提供未采纳原因 | 复用人工结论、工具审核及报告筛选规则 |
| 扫描规则 | 规则集概览 | 展示规则集用途、标准来源及启用的扫描器配置 | 按 OWASP、CWE、CERT 等及社区通用规则组织 |
| 扫描规则 | 社区规则库 | 展示本地规则库可用性并手动更新 | 扫描前建议准备可用的本地规则和漏洞库 |
| 整改报告 | 项目与资产条件查询 | 按业务项目和资产联动查询单资产整改报告，可查询、重置并进入项目汇总报告 | 后端先按归属和资产筛选，再取最近最多 200 份报告，避免旧项目被全局最近列表截断 |
| 整改报告 | 报告列表 | 按扫描资产和记录查看整改报告及问题数量 | 台账条数与依赖合并后的整改组数分别呈现 |
| 整改报告 | 单资产导出 | 在线查看 HTML，导出 Word、PDF | 保留原始问题、审核、整改建议及未纳入项说明 |
| 整改报告 | 项目汇总导出 | 按项目扫描轮次汇总覆盖范围、资产状态、风险及分资产明细 | 明确失败、取消、未扫描及部分范围；首次项目归档固定内容 |
| 整改报告 | 历史资产报告 | 项目中选择资产历史后查看、导出其原始报告 | 沿用原扫描编号与采纳记录，不伪造全项目报告 |
| 整改报告 | 红色加粗资产标识 | 扫描基线中标注 JAR、远程 Git 或本地代码、资产名称和来源 | JAR 优先使用本次扫描记录的包名；HTML、Word、PDF 一致 |
| 整改报告 | 业务运行版本 | 展示业务 Java 或 Node.js 版本 | 避免将前端 Node.js 项目按 Java 版本约束升级建议 |
| 整改报告 | 数量对账 | 展示原台账、纳入整改、合并整改组、未纳入及变化数量 | 组内保留问题编号和 CVE，支持与台账逐项对照 |
| 整改报告 | 后台补充联网核实 | 已完成的联网扫描可异步补查依赖版本依据，列表显示排队和处理状态 | 无需重新扫描或审核；复用 24 小时内有效依据；核实预算可配置，未完成项保留真实原因 |
| 整改报告 | 依赖整改依据 | 展示可核实的修复版本、来源及兼容性建议 | 未核实项明确保留人工判断要求，不编造可用版本 |
| 整改报告 | 中文导出与分页 | Word 嵌入宋体、黑体；PDF 保持报告样式及分页 | 当前生产使用已追踪的 simsun.ttf、simhei.ttf |
| 整改报告 / 验收 | 原报告问题追踪 | 按归档报告跟踪问题、整改说明、提交编号与记录人 | 原报告清单不随后续扫描任意变化 |
| 整改报告 / 验收 | 关联验收复扫 | 从原报告发起复扫，并选择验证批次逐条核查 | 区分未检出、仍存在等结果；不把未执行检测直接视为通过 |
| 工具管理 | 多模型配置 | 新增、编辑、删除或停用模型工具，切换当前使用工具 | 支持内置服务商及 OpenAI 兼容接口 |
| 工具管理 | 连接参数 | 配置服务地址、模型及 API Key，维护启用状态和当前工具 | 内置服务商可预填参数，自定义服务填写兼容地址 |
| 工具管理 | 配置持久化 | 本地数据库保存模型配置和加密密钥 | 重启后恢复；页面不提供密钥明文读取 |
| 系统设置 | 扫描器与运行状态 | 展示本地扫描器、可用性及运行环境信息 | 本机或容器需安装、启用对应工具 |
| 系统设置 | 本地部署说明 | 展示单机运行及规则、漏洞库准备要求 | 未启用模型时不调用模型接口；联网扫描仍按所选模式访问外部依据源 |
| 通用界面 | 主题与时间 | 多主题切换、统一东八区时间显示 | 使用真实运行数据；验证预览标签仅用于单独验证环境 |
| 通用兼容 | 历史链接与编号 | 保留资产 ID、扫描 ID、问题 ID 和原详情链接 | 新业务项目参数使用 businessProjectId；旧 projectId 仍表示扫描资产 |

## 当前边界

| 项目 | 当前行为 |
| --- | --- |
| dist 目录或 ZIP 独立上传 | 尚未提供对应资产入口；不能把现有 Git / JAR 支持表述为支持直接上传 dist 扫描。 |
| 前端产物与源码 | 产物压缩、混淆、默认忽略规则及缺少 lockfile / SBOM 会影响检测，前端源码与产物不等价。 |
| 自动修复代码 | 当前提供检测、审核、建议与验收，不直接自动修改业务仓库。 |
| Git “已同步” | 表示最近一次拉取成功，不保证远端之后没有新提交。 |
| 后台 Git 调度 | 当前按单应用实例部署实现；多实例共享数据库需要额外的分布式任务租约设计。 |
| 历史展示口径 | 项目轮次、资产独立历史分别保留真实范围，不用旧结果补齐失败资产，不合并为伪造的一次全项目扫描。 |
| 永久清理 | 普通资产移除保留历史；运维永久清理需明确限定资产，并核查关联记录、生成文件和可定位备份，不作为普通删除按钮默认行为。 |
| 额外字体 | 本次新增但未被代码或 Dockerfile 引用的字体及索引保留本地，不随本次功能提交。 |
